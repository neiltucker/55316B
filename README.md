# 55316B Administering a SQL Database Infrastructure 2025

**Courseware Access:** [Software Tutorial Services](https://www.softwaretutorialservices.com/course/55316b)  
* **Duration:** 5 Days (15 Modules)  
* **Audience Level:** Intermediate  
* **Format:** Instructor-Led / Bootcamp  

---

## Course Overview

This five-day instructor-led course provides students who manage SQL Server 2025 and Azure SQL databases with the knowledge and skills needed to administer a SQL Server 2025 database infrastructure. The material is also useful to individuals who develop applications that deliver content from SQL Server databases. In addition to SQL Server 2025 and Azure SQL Database, students will learn about SQL Server Management Studio 22 (SSMS 22).

> **AI Chat Assistant:** This course features an integrated, interactive **AI Tutor** available 24/7 directly within the courseware platform at no additional cost. Learners can ask questions in real time to explore SQL Server infrastructure administration, investigate authentication models and data encryption methods, and review PowerShell automation techniques.

---

## Audience

The primary audience for this course is individuals who administer and maintain SQL Server databases. These individuals perform database administration and maintenance as their primary area of responsibility, or work in environments where databases play a key role in their primary job. The secondary audiences for this course are individuals who develop applications that deliver content from SQL Server databases.

---

## At Course Completion

After completing this course, students will be able to:

* Authenticate and authorize users using Windows and SQL Server authentication modes, server and database roles, and granular permission management in SQL Server 2025 and Azure SQL Database
* Protect data using SQL Server Audit, temporal tables, Transparent Data Encryption, Always Encrypted, and Dynamic Data Masking in SQL Server 2025 and Azure SQL Database
* Design and implement comprehensive backup strategies and perform full, differential, transaction log, and advanced restore operations including point-in-time recovery in SQL Server 2025
* Automate database management using SQL Server Agent jobs, schedules, multi-server management, alerts, notifications, Database Mail, and PowerShell with the SqlServer module
* Monitor and trace SQL Server 2025 infrastructure using Dynamic Management Views, Extended Events, Performance Monitor, Management Data Warehouse reports, and structured diagnostic methodology, and transfer data using bcp, BULK INSERT, SSIS, and data-tier application packages
